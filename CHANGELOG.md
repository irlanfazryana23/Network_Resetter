# Changelog

## 1.0 — Initial release

- Simple English desktop interface with connection checks.
- DNS-cache clearing and optional DHCP renewal for a selected adapter.
- Winsock reset and an advanced full adapter reset.
- Saved settings, activity logs, progress, and stop controls.
- Separate repair and restart confirmations.
- Portable Windows executable with the app icon.
- MIT license, build instructions, and Windows build workflow.

Validation: the project owner tested the simplified 1.0 app in a Windows VM and reported successful operation. Build and static checks passed. Automated checks do not execute network operations.
